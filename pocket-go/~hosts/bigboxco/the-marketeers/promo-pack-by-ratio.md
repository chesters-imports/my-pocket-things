## Ratio cheat sheet (for AI resize QA)

| Family | Rough ratio | Resize hint |
|--------|-------------|-------------|
| Square | 1:1 | Scale uniform; watch logo clear of neck |
| Soft landscape | ~4:3 / 6:5 | Mild crop from square master possible |
| Landscape | ~3:2 → 2:1 / 16:9 | Prefer landscape master |
| Website strip | ~3.7:1 | Dedicated strip layout — don’t squash from 16:9 |
| Leaderboard | ~8:1 | Dedicated — never upscale from strip |
| Portrait | ~2:3 → 1:2 | Dedicated tall master |

**QA rule (draft):** every AI resize must land in a named family above and pass a human glance before ship. Orphan sizes get flagged.
