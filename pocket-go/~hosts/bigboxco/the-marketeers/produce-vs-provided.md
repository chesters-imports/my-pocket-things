# Produce vs provided

What the Podio pack **lists** is not the same as what Marketing Art must **make**. Clarified with Kitten 2026-09-14.

## Unique sizes

Across the full master list (promo + client-area + social + sales + legacy + ad-hoc quartet):

**85 unique width×height pairs** (after collapsing duplicates like the same size appearing in Coming Soon and Out Now, or promo + client-area).

That count includes legacy Governor extras and one suspicious Podio line (`300×4140` — almost certainly a typo).

Core recent promo template alone still has a large banner/button matrix; duplicates across status/locale rows inflate *line count*, not unique canvas sizes.

## Clarifications

### “Chinese localized”
Not a mystery asset type. It means **the same kind of promo buttons/banners, sized for Chinese/localized placements** — the four sizes listed (360×360, 500×250, 500×500, 526×314). Copy/art may be CN-specific; the row is a **size set**, not “make Chinese somehow.”

### Badges / characters / symbols / logos
**Provided to Marketing Art** (game/art source). Pack lists them because the ZIP/handoff must include them — not because this team paints them from scratch.

### Free Spin / Main Game backgrounds
**Provided.**
