# Common banner sizes (2026)

Quick reference for Marketing Art. Pair with [[promo-pack-keep-cut]].

Display / IAB fixed sizes still cover most programmatic and Google Display inventory. Social and responsive formats are ratio-based assets rather than one fixed pixel size.

## Display / IAB — build these first

| Size (px) | Name | Why it matters |
| --- | --- | --- |
| 300×250 | Medium rectangle | #1 everywhere — desktop + mobile |
| 728×90 | Leaderboard | Desktop header / footer standard |
| 320×50 | Mobile banner | Default mobile web |
| 300×600 | Half page | High-viewability sidebar |
| 160×600 | Wide skyscraper | Desktop sidebar |
| 320×100 | Large mobile banner | Stronger mobile than 320×50 |
| 970×250 | Billboard | Premium desktop |
| 336×280 | Large rectangle | Near-universal in-content |

**Lean starter set** (max coverage / min production): **300×250, 728×90, 320×50, 300×600**

## Social / Meta / Google responsive

- **1:1 square** — 1080×1080 (safe universal)
- **4:5 portrait** — 1080×1350 / 1440×1800 (mobile feed)
- **9:16 vertical** — 1080×1920 (Stories / Reels)
- **Google Responsive Display** — 1200×628 landscape + 1200×1200 square (+ portrait if available)
