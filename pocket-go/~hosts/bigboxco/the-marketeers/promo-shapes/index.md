# Shapes (all art packs)

Visual board of **every pack size we care about**, grouped by similar shape - not promo-only.

Boxes scaled to the same max side. Labels show which pack(s) use the size (Promo, Client, Social, Shot, GIF, Badge, Tagged, Legacy, Ad-hoc).

- **Solid teal** = exact same ratio (clones)
- **Dashed amber** = nearby ratios compared
- **Grey** = solo ratio in that family
