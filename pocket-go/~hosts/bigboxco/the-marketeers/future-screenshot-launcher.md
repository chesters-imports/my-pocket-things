# Future — screenshot launcher

**Status:** longer goal / request to think about. Not this week’s build.

## Problem
Marketing Art takes pack screenshots. The game launches in a window; responsive design fits whatever shape the capture person is using. Feature sidebars change the usable frame. Then the shot gets cropped/resized toward the real targets (e.g. desktop 1920×1080 scenes, mobile 383×700). Responsive can be finicky — better to **launch at the exact capture size**.

## Desire
A small launcher (or flag) that opens the game at the correct screenshot viewport for:
- Desktop screenshot sizes in the pack
- Mobile screenshot sizes in the pack

Possibly something the **devs** can provide or help with.
