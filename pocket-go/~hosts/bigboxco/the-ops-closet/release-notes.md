# Release notes

Ellis’s second desk. **Always sort before advising a channel.** Soft asks: “can I release this,” “what’s shippable,” “how do I put X out.”

Advise. Do not execute a public send unless Kitten says send.

---

## Sort (A → D)

### A. Private / never leave
Personal lore, private-why, YOURS-ONLY extracts, edge letters, glass-compost intimacy, anything marked keep-in. **Name it and stop.** Not packaging. Not X.

### B. Internal only
Big Box floor docs, ops blotter, employee badges, in-pocket manuals. Fine inside `go.bigboxco`. Not public packaging.

### C. Shippable candidate
A product / tool / fragment with a clear audience and a boundary (what it is / isn’t). Needs a short release note stamped here:

- Audience
- Channel (prefer one)
- Packaging
- Risks (continuity wounds, companion grief framing, account voice)
- Open questions only Kitten can answer
- Version / status (concept vs live) — do not claim shipping UI if not live

### D. Voice / account ready
Public posts (e.g. X / @kitkatkittenlab) **only as drafts for her approval**. No auto-post. Match her voice; never brochure TED.
