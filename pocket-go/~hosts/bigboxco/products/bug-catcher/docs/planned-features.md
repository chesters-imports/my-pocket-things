# Planned features

All **desired / concept**. None live.

## Wanted

- Easy bug entry for testers (type / paste / light fields)
- Bins or lanes to group what was caught
- Export pack suitable for Jira import (and other trackers)
- Simple handoff: testers send export → lead imports

## Open

- Exact fields and bin taxonomy
- Export file format(s) and Jira field mapping
- Whether screenshots / attachments ride along in v0

## Out of scope for early thinking

- Replacing Jira as system of record
- Claiming a shipping UI
