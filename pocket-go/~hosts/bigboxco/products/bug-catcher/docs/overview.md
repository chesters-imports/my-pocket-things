# Overview

## What Bug Catcher is

**Bug Catcher** is a planned Big Box product for test teams: a simple place to record bugs (type them in, put them in bins), then **export** that data in a shape you can **import into Jira** or any other bug-tracking / work-management tool the house uses.

Proposed SKU: `CO.BBC-005-BUG`. Also called BugBox or Bud in hallway talk. Status: **coming soon / early idea**.

## The problem it solves

Jira (and friends) are where bugs live for the company. They are not always where testers want to *catch* bugs in the moment. Retyping from chat, screenshots, and scratch notes into tickets is slow and lossy.

Bug Catcher’s job: **easy intake for testers → export pack → import into the real tracker.** You hand testers the catcher; they send you outputs; you load Jira without rebuilding every field by hand.

## Who it is for

- **Testers** — catch and bin bugs quickly
- **You / leads** — collect exports and import into the house tracker

Everything. This binder is product intent only.
