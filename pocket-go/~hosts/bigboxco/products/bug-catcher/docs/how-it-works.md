# How it works

**Concept loop — not a live walkthrough.**

## 1. Give testers Bug Catcher

They get a desk that is easy to type into. Low friction beats a full corporate ticket form at the moment a bug appears.

## 2. Catch into bins

Bugs land in bins (how bins are labeled — area, build, severity — still open). The point is organize-as-you-catch, not perfect workflow theater.

## 3. Export

Tester (or lead) exports the caught set in a format aimed at tracker import — CSV, JSON, or whatever Jira / the house tool accepts. Exact format is planned work, not decided here.

## 4. You import

Outputs come back to you. You import into Jira or another management tool. Bug Catcher is the catcher and the bridge — not a replacement for the company tracker of record.
