# Getting started

## Open the desk

1. Launch from Deck Host (`SPR-403`) or run `prod/run-sopr.bat`.
2. You land on an empty state: **No document selected. Please select a document.**
3. Use **Open…** (Ctrl+O) or **New document…** (Ctrl+N).

The vault manager is the file face for `safe_box`: folders, new document, rename, move, delete. Documents are `.sopr` files.

## Create or open a bag

- **New document** invents a bag in the vault.
- **Open** picks an existing `.sopr`.
- The thin strip under the menu shows the current document path.

## Add your first scrap

1. Stay in **Document mode** (Ctrl+1).
2. Pick or create a section in the left rail.
3. The **composer** sits at the **top** of that section bucket — always.
4. Choose fragment type: **Text**, **Image**, or **Table**.
5. Write the leaf (or upload / fill the grid) and store it (Ctrl+Enter).

Stored fragments drop **below** the composer. You keep typing at the top. You do not leave the page. There is no second "notes" field — another thought is another sopr fragment.

## Look at what you made

- **Resort (kanban)** — Ctrl+2 — drag cards between section columns.
- **Print / reader** — Ctrl+3 — TOC + outline body (skips Loose / unbinned intake).
