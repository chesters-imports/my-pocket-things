# How it works

**Concept loop — not a shipping walkthrough.**

## 1. Connect the allowed AI

Install or paste credentials for the AI API your company permits for this work. The product does not smuggle an unapproved model. “Remote” means the heavy lift can live on that API, not that anyone’s key is fine.

## 2. Drop two masters

- **Square master** — the composition that must survive 1:1 and near-square buttons
- **Wide master** — the composition that must survive landscape banners and leaderboards

Two truths beat one stretched lie. The desk (when built) should pick or blend from the right master per target aspect instead of naively scaling one file into every hole.

## 3. Give it the size list

Paste or load a formatted list of target sizes (width×height, and later: deliverable name, format, pack). The the-marketeers **per-game size master list** is the obvious house source to feed or import.

## 4. Hit run

The API pass generates candidates for each size. You get a folder or gallery of banners out — then human QA against the house checklist (readable at small size, logo clear of face/neck, one CTA, status subordinate, and so on).

## 5. Layout / best practices (planned)

Somewhere in the loop: rules that keep title, status, logo, and CTA honest across crops. That may be editable layout presets, baked teaching, or both. Open on purpose — see {{link:crate.B160B0C0E0004B45|Layouts and best practices}}.
