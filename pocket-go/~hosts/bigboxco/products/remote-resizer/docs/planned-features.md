# Planned features

Everything below is **desired / concept**. None of it is a live desk capacity.

## Core (wanted)

- Connect / store allowed AI API credentials for this desk
- Upload or point at square master + wide master
- Paste or import a formatted size list (width×height; later deliverable metadata)
- Run batch that outputs one candidate (or small set) per size
- Download or vault a banner pack

## Layout / quality (wanted, design open)

- Layout presets and/or taught best-practices pack
- Tie-in to house QA checklist energy (small-size read, logo clearance, single CTA)
- Optional import from the-marketeers size inventory

## Explicitly out of scope for v0 thinking

- Replacing human art direction
- Unapproved model endpoints
- Claiming shipping UI chrome that does not exist
