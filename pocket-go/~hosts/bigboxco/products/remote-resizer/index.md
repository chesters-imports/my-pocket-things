# Remote Resizer

{{div:.bbc-lede}}
A marketeer desk for turning two masters and a size list into a full banner set. Plug in the AI API you are allowed to use, drop a square banner and a wide banner, paste the sizes you need, hit run, get the pack.
{{/div}}
{{/div}}

**Status: coming soon / in progress.** There is no live desk yet. This landing and the Document bay describe the product Kitten is inventing — not buttons you can click today.

Games are sold by the banner. Marketing Art already keeps official size inventories under {{link:crate.0B27B459D801AD1B|the-marketeers}}. Remote Resizer is the machine that should eat that list instead of burning a human on every crop.

{{div:.bbc-pillars}}
{{div:.bbc-pillar}}
**MASTERS**
One square, one wide. The creative truth lives there — not in eighty manual exports.
{{/div}}
{{div:.bbc-pillar}}
**SIZES**
A formatted list of target widths and heights (and later, packs from the house inventory).
{{/div}}
{{div:.bbc-pillar}}
**RUN**
Allowed AI API does the resize / recompose pass. You review the set, not rebuild it by hand.
{{/div}}
