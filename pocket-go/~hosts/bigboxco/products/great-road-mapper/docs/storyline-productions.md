# Storyline productions

**Something to consider — a configuration use case, not a separate shipping product.** Great Road Mapper was built for multi-title production boards. The same inventions work when the “title” is a story unit.

## Why this fits

GRM does not care that a title is a slot game. It cares about:

- An immovable **ship** (here: lock night, air date, or “this story must be true by”)
- A **spine** of phases and gates reverse-filled from that date
- **Templates** that own structure; **variations** that only change week numbers
- Optional **linked titles** when two machines belong to one story

Storyline production has the same cognitive pain: many craft goals, one hard date, and a brain that should not rebuild the calendar forward from “we started writing.”

## How you might wire it

| GRM piece | Storyline reading |
|-----------|-------------------|
| Title | Episode, arc, season pass, feature, or lore drop |
| Ship | Lock / air / publish / “audience may know this by” |
| Template | Story craft spine (premise → outline → draft → notes → revise → polish → lock) |
| Variation | Same spine, different speeds (half-hour vs hour, soft arc vs finale) |
| Gates | Table read, notes lock, picture lock, drop date |
| Linked titles | Season machine + episode machines; A-plot / B-plot twins |

Exact bin names are **your** template — not baked into GRM’s product identity. Same rule as company rebrand twins: an example of how to use configurations, not canon.

## Release order of information

If the greater project is a **network of toys and systems** that tell one story, GRM can hold **when** each unit must land and what craft bins stand behind that date. It does not replace a catalog of *what* exists in the world — it roadmaps *when work and reveals happen*. Pair with other Big Box desks for talk and compile (see the suite note on boxing a story network).

## What this is not

- Not a claim that GRM ships “TV mode”
- Not a replacement for a script tool
- Not Nucleus/BSG or any day-job slate renamed as story

It is an option on the shelf: reuse reverse-from-ship so story calendars grow backward from truth dates.
