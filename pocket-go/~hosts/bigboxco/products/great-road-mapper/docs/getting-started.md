# Getting started

## Open the desk

1. Launch Great Road Mapper from Deck Host (ROM `great-road-mapper`), or run `run-grm.bat` from the product `prod` folder.
2. You land on the **Production board** with tabs for Board, List (default), Gantt, By quarter, Phases & gates, People, and Configurations.
3. Use the theme control for light or dark.

## Add a title

Click **+ Title**.

You will fill:

| Field | Meaning |
|--------|---------|
| **Code** | Required title code (e.g. a quarter game code) |
| **Name** | Optional working title |
| **Product model** | Which spine / configuration to mint from |
| **Ship date** | Optional. Quarter follows ship date; blank leaves an unscheduled corner |
| **Line** | Product line filter bucket |

Schedule first. Theme, math, and crew can live on the ticket later — they are not required to open a board slot.

Ship date reverse-fills the model’s bins. Leave ship blank for empty phase dates until you set one.

## Filters

Above the views:

- **Product line**
- **Schedule lane** (filled from live titles)
- **Lifecycle** — Planning, Active, Scope change, Shelved, Cancelled
- **Quarter chips** — multi-select

Clear filters when the board looks empty and you expected titles.

## Open a title

Click a card or list row. A drawer opens for that title — phases, gates, people pins, twin links, and edits that ask for a reason when the schedule moves.
