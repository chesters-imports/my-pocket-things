# Great Road Mapper documentation

This is the help binder for **Great Road Mapper** (`CO.BBC-001-GRM`), Big Box Company’s personal production board.

It is written for people who will use the product — not as a private note between assistants. The important invention to understand is **Configurations**: reverse-from-ship schedule machines so complex roadmaps do not have to be rebuilt by hand for every title.
