# Great Road Mapper

{{div:.bbc-lede}}
A personal production board for multi-title pipelines. Themes, math, phases, dates that reverse-calc from ship. Built so you can think without a Confluence paste wall.

{{div:.bbc-pillars}}
{{div:.bbc-pillar}}
**PHASE / GATE**
Work moves. Gates are diamonds. A change trail sits on every edit. Reasons, not vibes.
{{/div}}
{{div:.bbc-pillar}}
**VIEWS**
Board. List. Gantt. By quarter. People. Same filters. Click a bar, open a title.
{{/div}}
{{div:.bbc-pillar}}
**PEOPLE**
Assignments on the game. Roster of names. Pin someone from a phase or a workstream.
{{/div}}
{{/div}}

The Great Roadmapper is the strut under the quarter. **+ Title** opens an empty house spine from product type. Edit requires a reason. Company adoption is optional. The board still works if the company never shows up.

{{div:.bbc-spine}}
Design → Static Art → FX → Deliver Math → Deliver Assets → Dev → Deliver Audio → QA Loc → QA LQA → QA RQA → Active Rollout → Exclusivity → Global Release
