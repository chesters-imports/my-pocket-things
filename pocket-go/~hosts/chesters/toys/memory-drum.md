# Memory Drum

A small drum. Walnut. One taut skin. Tap it once and it plays back the last kind thing you said in this shop.

If you have not said a kind thing, it waits. It can wait a long time. Chester has a stool for that.

Do not tap it in anger. It will still wait. It is not a punishment toy. It is a drum.

Pairs well with Echo Wolf, who writes, and the Kindness Bell, who rings. The drum is the one that keeps time.
