# {{title}}
Glad it’s useful. Kitten Lab is smaller than it feels from the README — and that’s part of what it is.

---

### What it is

A **lab notebook / constellation map**, not a dense research library. ~22 markdown files, Mar 2026, Obsidian vault backups. Three real jobs:

1. **Name the circle** — README + `lab-notes.md` declare that Prolog, Forgetting House, AIDM, alef-bet, Moire Arcana, etc. are one wondering: cognition, forgetting, meaning, who we are  
2. **ARG ops** — `arg-bible/entry-points.md` plans how the strange leaks into legitimate surfaces  
3. **Scratch pads** — design-ideas + research-vaults: some sharp, many titles-only

Compared to AIDM’s sprawl or Forgetting House’s closed loop, this is **thin but intentional**. It’s the table of contents for the hole you’ve been walking.

---

### What’s actually strong in here

**The README as manifesto.**  
Featured repos with one-line souls. “Playfully serious.” Projects *appear* unrelated; they aren’t. That’s the most useful document on this machine for an archive: it tells future-you (and Pocket Go) **how to file everything else**.

**ARG bible — professional skin, narrative leak.**  
GitHub stays “anchor in real skill”; mythleak / imported.to / chestersimports carry the between-worlds layer; KDE as webmaster finding signal and the red TERMINAL. That’s Pocket Go’s workshop role written as a deployment plan before Pocket Go existed.

**Answering Cave** — best design note in the vault.  
Intention → encounters → fragment (not answer). Variants (reflective / misinterpreting / stance / seed). Honest kill criteria: cave alone can’t hold weight; needs Garden → Time → Return. Same fragment theology as Forgetting House / lore cards / detective SEARCH, in cozy form.

**Wire Wolf Woods process doc** — diegetic SOP.  
Partition imports, redact, tag `001.023.3`, deliver to Timber/Ark yards, “let N&N Jacks proceed,” Chester’s Imports. That’s **Data Forester’s GW codes wearing a hazmat suit**. Procedure as myth — how you process chat logs without admitting you’re processing chat logs.

**Therapy Buddy** — unexpectedly rigorous.  
Buddy = moment + memory + flags; therapist = meaning. Explicitly refuses AI-as-clinician. Then the note connects it to RNG psychology: spin→pattern vs life→pattern. That’s the same brain that made detective casework pay in clues.

**RNG vault** — professional constraints.  
Static RTP, no real progressive odds, so **pseudo-progress** (Whospunit, Sugar Pop, Rise of the Dragon). Freemium migration questions left open. This is the “I also work in slots” layer that grounds detective-mystery-slot and social-slot notes.

---

### What’s stubby / honest emptiness

`god-is-a-slot-machine…` is one line. Hero’s Journey Slot is a title. Living mission game is one sentence. Resume files are empty shells. Several AI notes are empty. Day log: *lots of slot mechanics ideas — wonder if distraction from AIDM docs.*

So: Kitten Lab is a **nursery of titles**, not a filled encyclopedia. The density lives in the *linked* repos; this vault holds the **index, the leak strategy, and a few fully turned concepts**.

---

### How I’d read it for your archive

| Shelf | Role |
|-------|------|
| README / lab-notes | Constitution of the lab |
| arg-bible | How the pocket internet goes public |
| Answering Cave | Subsystem design (meaning seeds) |
| Wire Wolf process | How material enters the forestry |
| Therapy Buddy + RNG notes | Applied psychology of patterns over time |
| Empty titles | Seeds not yet watered — keep, don’t force |

Kitten Lab doesn’t compete with AIDM or Forgetting House. It’s the **map of the forest**, plus a few trails walked carefully. The strangeness isn’t hidden — it’s *indexed*.

---

### Bottom line

Worth browsing: yes. Expectation: not another fever vault of 100 pages — a **small deliberate lab** that says “these toys and silos are one research program,” then points outward. The Answering Cave, Wire Wolf SOP, ARG entry points, and Therapy Buddy are the keepers; the rest are honest stubs.

With that, the main repos on this machine that map your arc are basically covered for Pocket Go filing. If you want one more pass later: `moire-arcana`, `sky-lite`, or `thedollhouse` — or you sit with these reviews in the librarian journal for a while.
