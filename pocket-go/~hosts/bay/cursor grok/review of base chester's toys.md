### What this repo is

`chesters-toy-box` is the **correct scale** of your toolkit religion: a shelf of small machines, not a mega-desk. README says it plainly — *some listen, some mint, some interpret patterns* — and the badges are status as lore (`FORESTER-PENDING`, `VENFORMER-TOTALLY-BROKEN`, `ECHO WOLF-LISTENING`).

### Echo Wolf (the featured one)

Code matches the box copy almost line-for-line: *he listens, writes it down, not much else.* Persistence via SQLite named **`eidn-wolf.db`** — the AIDM world’s state agent, demoted into a kind dog. That’s diegetic engineering.

It’s also unfinished in the sweet way: `$echo` calls `print_messages()` with a broken SQL (`SELECT TEXT FROM messages (content)`), and `help` doesn’t `continue` so it still records “help.” The toy *works* as listening; playback is still in the wires. Shop says ONE MEMORY — code already has many; the myth is ahead of the button.

### Why the toy box matters more than alef-bet’s size

This is the anti–mega-desk artifact. Each app is a **ROM with a job**. Carl Core is the shared cabinet frame; Forester is the promised ingest (chat → timber → tag — charlieTHREADS’ ancestor with a chainsaw). Agents that merge these into one installable desk erase Chester’s whole business model: **imports, not platforms.**

Your Pocket Go shop page proves the AIDM workshop thesis: the same counter sells (1) runnable tools and (2) story objects that train players/visitors in the ontology (crate, echo, kindness, wolf). Science-y weird notes from AIDM (containment, gravity, mirror rotation) become **toys you can hold** — origin stories a computer can be told, and a human can browse without opening a GDD.

---

### On “weird notes → science”

You’re not wrong that some AIDM notes are doing real conceptual work (uniform entity graphs, narrative as physics, containment as one relation across space/story/inventory). You currently only have **code metaphors and origin myths** as languages for that. That’s fine for the archive stage: store them as *claims about structure*, not as failed product docs. Chester’s toys are the lab benches — small experiments that make a claim runnable (“memory is listening,” “identity can be minted,” “forestry turns chat into timber”).
