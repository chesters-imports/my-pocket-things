### What this folder actually is

> DOCUMENTATION IS WRETCHED — proceed with wreckless uncertainty.

The clean spine (when you ignore the mess) is small:

1. **Everything is a VEN** — one object type; meaning comes from properties + dynamics  
2. **Containment is the universal relation** — room→bed, quest→event, Mira→memory, same graph edge  
3. **Four functional actors** — PC ↔ AIDM ↔ EIDN (world state) ↔ EIVE (emotional/energy vectors)  
4. **Narrative doesn’t end at convergence** — resolved threads feed more story (`adm-overview.md`)  
5. **MiraOnline** — diegetic internet inside the world (`imported.to`) — Neocities + ARG + MMO lore blogs  

That last one is the pocket internet wearing a game jacket. Silo wasn’t a side quest; it was a **prototype substrate** for MiraOnline / imported.to.

### What you were doing (for the archive)

You were trying to design a **uniform narrative OS**:

- No separate item/character/quest/world systems — only VENs + props  
- Story as physics (`narrativeGravity`, impact, decay)  
- Multi-agent dream: AIDM narrates, EIDN holds truth, EIVE holds feeling  
- Players and NPCs share the same ontology  
- The world’s internet is real and visitable (MiraOnline)  

**Why:** because scripted games end, and chatbots forget. You wanted **ongoing meaning** — continuity with weight — which is the same itch as charlieTHREADS gravity, TPS time, and Prologue’s remember/look/think.

The disorder happened because the dream was bigger than any single implementation language, and the vault became the only place that could hold all three layers at once.
