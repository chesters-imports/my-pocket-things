## Zones for rotation
### Zone 1 — Abandoned Hearth
**Abandoned Hearth** (kitchen + empty dining).
Daily light: counters / sink / crumbs / trash+cans
Weekly deep: mop, fridge wipe, appliances, under sink

### Zone 2 — Cabin Room + Hallway Room
**Cabin Room** (living / main office) + **Hallway Room** (art space).
Daily light: clear main surfaces, trash+cans, quick path
Weekly deep: dust, vacuum/mop, under/around desk & art piles (gentle — don’t start a project spiral)

### Zone 3 — Baths
Downstairs shower bath + upstairs half bath.
Daily light: swish & swipe, trash
Weekly deep: scrub shower/tub day, floors, mirrors

### Zone 4 — Port Room + Landing
Kitten’s bedroom + upstairs landing.
Daily light: floor path clear, trash, bed-ish
Weekly deep: dust, floors, surfaces

### Zone 5 — Mirror Rooms (M + W)
Daughter’s room + son’s room.
Daily light: trash+cans + one clear path (kid-safe ask)
Weekly deep: floor reset, wipe surfaces (with/without kids as fits)

### Zone 6 — Dragon (declutter lane)
Dragon bedroom — go-through zone, not a normal light-clean every day.
Use as Medium/Large picks or weekend deep: one box / one pile / 15 minutes. Progress over perfection.

## Cadence
- **Daily:** house-wide cans+trash collect + light-clean **one** active zone (1–5)
- **Care pockets:** pick ONE Easy/Medium/Large (zone light-cleans show as Medium)
- **Weekend:** one harder item (mop a zone, deep bath, or Dragon 15)
- **Friday:** easy mode / kids home — prefer Easy picks + light Zone 5 if needed
- **Required** (separate rails): laundry Mon/Tue, Thursday trash, CookUnity
