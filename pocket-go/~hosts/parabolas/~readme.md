# about this chamber

Named for the Tool song-spiral (*Parabol / Parabola*) and for stories that bend back into themselves. Occult, heavy, precise - a writing room for darker lessons.

Coat: press-house bone (threshold / fascia / fold-alcove / curve-rack / blotter-desk / street-foot). Leaves live as bound curves on the rack. Environment on the room letter.
