# Deck host → desk-as-OS

## Grief + clearer dream
Deck host glued two jobs: **shape** (artistry, constrained window) and **runtime** (local Python parent, hyper-local servers). The runtime job blocks internet/distribute.

Chromium-as-app can keep shape (icon, not a bat-file script). www stack stays something that could go on the internet.

## Truer mouth
Fullscreen desk (e.g. Sophia) launching ROMs *inside* feels more like a pocket OS than a middleman host. Original pocket-internet: pages as rooms, nested ROM doors — not twenty-five million orphan servers.

Tag bay as a launchable ROM fits. Host becomes optional coat, not the only door.
