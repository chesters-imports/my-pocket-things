# Marks

Rapid log. One mark in the brackets, the thing. Same marks for Hands and Carl. The room stamps them as gold boxes. Click `.` and `x` to cycle.

| mark | means |
|---|---|
| `[.]` or `[ ]` | task — still holding |
| `[x]` | done |
| `[>]` | migrated |
| `[<]` | scheduled / paired |
| `[o]` | event |
| `[-]` | note |
| `[*]` | look at this line |

TPS if a line needs a true day. Librarian if a page wants vault. Charlie if a word needs weaving.

Do not stamp copy day.

## Month folders
Dated history lives under `2026-09/`, `2026-10/`, … — month spread, week spreads, daily leaves. October never overwrites September. Open/close still ink the living Today face; dated leaves are the archive spine.
