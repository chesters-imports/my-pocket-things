# codes.

A `^OT-008.T01.B002.L03` is one chain address. OT, NT, and ONT are groups. Then the log number, trunk, branch, and leaf. Using a cite mints the whole chain here. Click a depth to open that bin. Notes that used the address look through on the node. Compost headlines and tags for that ZIP sit on the node too - they are not minted as extra pages.
