# Type

Shared catalog: `/styles/fonts.css`. In a coat:

```css
font-family: var(--font-arcade);
```

Live pangrams also live at `go.law` → type. This Help card is the editable field guide — grouped by **style**, with a sample line so you can see the face.

Favorites: `--font-arcade`, `--font-glass`, `--font-px437`, `--font-hand`, `--font-notebook`, `--font-distress`.
